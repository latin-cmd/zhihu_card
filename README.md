# Directus + MCP Activity Web

Astro SSR activity page for a Luma-style city event experience.

## Local

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview -- --port 4322
```

The current content is in `src/data/content.ts`. It mirrors the intended Directus collections and can be replaced with live Directus API calls when the CMS is available.
